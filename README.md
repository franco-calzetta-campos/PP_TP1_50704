# Información del proyecto

## Resúmen general
Programa demostrativo de un modelo a escala de Eventos Universitarios en el que se almacenan las inscripciones de estudiantes a actividades específicas dentro de eventos universitarios.

## Clonar y construír
En terminal, con git instalado, ejecutar
> git clone https://github.com/franco-calzetta-campos/PP_TP1_50704
Luego, para compilar y ejecutar:
* Si está en windows
** Ejecutar "build.bat" (dentro o fuera de la terminal)
* Si está en Linux
** Aún con la terminal abierta, dentro de la carpeta clonada (cd PP_TP1_50704), ejecutar:
  > chmod +x build.sh
** Ejecutar ./build.sh
